# 要件定義書（v1）

## 0. 概要
- **目的**  
  マッチングアプリなどで連絡が途切れた相手に対し, 返信を促す “軽いLP” を簡単に作ることができるSaaS

## 1. 対象ユーザー / ペルソナ
- マッチングアプリ利用者やホストなど

## 2. ユースケース（MVP）
| ID | ユースケース |
|----|--------------|
| U1 | Webページとしてメッセージを公開して送りたい |
| U2 | 作成したメッセージページを一覧で管理したい |



## 3. スコープ（MVP）
### 含める機能
1. **認証機能**: Google / LINE ログイン
2. **プロジェクト作成機能**: メッセージ型プロジェクトの作成, URL発行
3. **ダッシュボード機能**: 作成したプロジェクトの一覧表示・管理
4. **公開ページ機能**: 作成したメッセージをWeb上で公開

### 含めない機能（将来の拡張候補）
- 有効期限切れのプロジェクト自動消去（追記：MVP完成後に追加実装しました）
- プロジェクト作成数制限（追記：MVP完成後に追加実装しました）
- 課金（Stripe）
- メッセージ型以外のプロジェクトタイプ（追記：MVP完成後にS3を用いたpictureタイプを追加実装しました）
- In-app browser 検知 → 外部ブラウザ誘導（403対策）



## 4. 機能要件（MVP）

### 4.1 認証 / 認可
- **ログイン方法**: Google / LINE アカウントによるログイン
- **認証要件**: プロジェクト作成・管理機能は認証必須

### 4.2 プロジェクト作成
- **入力項目**: プロジェクト名とメッセージ本文
- **自動設定**: 
  - slugはランダムに決定
  - プロジェクトタイプは `message` 
  - 有効期限は作成日時から31日後
- **URL発行**: プロジェクト作成時に一意のURLが発行される

### 4.3 プロジェクト管理（ダッシュボード）
- **表示内容**: ログインユーザが作成したプロジェクトの一覧
- **表示順序**: 作成日時の降順
- **表示条件**: 有効期限切れ1ヶ月後以内のプロジェクトのみ表示
- **操作機能**: プロジェクトの削除（所有者のみ可能）

### 4.4 公開ページ
- **アクセス方法**: 発行されたURLでアクセス可能
- **表示条件**: 有効期限内のプロジェクトのみ表示
- **表示内容**: Zaoralユーザが設定したメッセージ
- **詳細**: Zaoral_banckend3参照
