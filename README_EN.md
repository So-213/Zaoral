# Zaoral 


Zaoral is an application that helps you create web pages from messages to re-engage with contacts from dating apps who have stopped responding.

Users can create follow-up messages and publish them on the web to deliver attention-grabbing messages to their matches.

For more details, see the in-app page: [https://zaoral.vercel.app/zaoral](https://zaoral.vercel.app/zaoral)

## First Release

September 2025

## Development Period

Unknown

## Features

- **User Authentication**: Login with Google OAuth
- **Message Creation**: Simple message creation and publishing functionality
- **Project Management**: View and delete created projects from the dashboard
